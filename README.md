## ✨ What is this?

**Rihannah's Cyber Diary** is a personal fun website made to feel like a little digital room on the internet.

It's not a portfolio.

It's not a professional website.

It's just a little space that feels like me.

A place for:

- 📝 Random thoughts
- 💭 Little moments
- 📸 Memories
- 💗 Things I like
- 🌙 Late-night thoughts
- ✨ Pretty things
- 🌸 Random pieces of my personality
- 💻 A little bit of coding chaos

Basically...

> If my brain had a website, this would probably be it. 😭

## 🚀 Run It Locally

Clone the repository:

    git clone https://github.com/adeoyerihanat6-prog/Cyber_Diary
Move into the project folder:

    cd cyber-diary

Install dependencies:

    npm install

Start the development server:

    npm run dev

Then open the local URL provided by Vite.
